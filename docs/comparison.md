# Comparison protocol (Version 1 vs Version 2)

- **Version 1:** this design. One ChatGPT Work chat does all five stages alone. It is scored on accuracy only. It cannot earn an official lock.
- **Version 2:** a parent Grok Bot plus six child bots. It can seek a lock under these gates and is described as a same-family role split.

The official lock is not weakened so that Version 1 can earn one. Version 1 is scored outside the lock.

## Fairness

Both versions get the same case pack, rules, locked questions, and stopping rules. Neither sees the other's work or the key. The case must be fresh to both. The run cap is the same for both sides.

## Scoring

Scoring happens only after both versions are sealed. The scorer is the earlier key preparer from the ChatGPT side, who was not the live Version 1 chat and is not a live Version 2 role. That scorer uses the private key and a scorecard written in advance:

1. Accuracy on four dimensions: target/population; numbers and memberships (money to the cent, percents to 2 decimals); interpretation and claim ceiling; action and rationale.
2. Error list, with error types and whether they are shared.
3. Wall-clock time and operator hands-on time.
4. Usage and cost.

No winner is declared mid-run. Report limits plainly: one case is not a general accuracy claim. Report also that Version 1 had no independent reviewer and Version 2 is a same-family role split.
